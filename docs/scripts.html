crop-images.py Python
Image Cropper, Rescaler & EXIF Embedder
Recursively scans raw images, crops to a configured aspect ratio and positional anchor (center, top, or bottom), resizes using Lanczos resampling, embeds EXIF metadata (Title, Credit, License), and exports WebP files with macOS extended attribute preservation.
Options & Parameters:
  • CROP=center|top|bottom|none — Positional crop anchor strategy (default: center)
  • TARGET_W=1600 TARGET_H=900 — Output aspect ratio & pixel dimensions
  • QUALITY=85 — WebP compression quality percentage
  • SOURCE_DIR=path — Input directory containing raw stock photos
  • OUTPUT_DIR=path — Target destination directory for processed images
Usage Examples:
# 1. Default Widescreen Run (1600x900 Center Crop):
python3 utils/crop-images.py

# 2. Portrait Headshots (1200x1600 Top-Anchored Crop):
CROP=top TARGET_W=1200 TARGET_H=1600 SOURCE_DIR="./zz_unused/raw-headshots" python3 utils/crop-images.py

# 3. Pass-through Mode (No cropping, EXIF embedding & WebP conversion only):
CROP=none SOURCE_DIR="./zz_unused/raw-photos" python3 utils/crop-images.py

Usage Examples:

# Inspect block patterns directory

patterns2php.sh Shell
Lumina Theme Pattern Converter
Converts raw HTML block layouts from /patterns/html (or /parts) into production-ready WordPress PHP pattern files in /patterns/converted with esc_html_e() i18n translation functions, asset URI helpers, and clean Block Types comment manifests.
Options & Parameters:
  • -f or --force — Force overwrite existing PHP pattern files
  • [filter_keyword] — Filter conversion to files matching a specific string (e.g., hero)
  • [custom_folder] — Target custom relative source directory (e.g., parts)
Usage Examples:
# 1. Default Run (Skip existing PHP patterns):
./utils/patterns2php.sh

# 2. Force Overwrite (-f / --force):
./utils/patterns2php.sh --force

# 3. Filter by Filename Keyword:
./utils/patterns2php.sh hero

# 4. Target Custom Directory (e.g., Template Parts) with Force Overwrite:
./utils/patterns2php.sh parts header -f
