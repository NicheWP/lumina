    color-defaults

    $color-defaults: (
    color:           null,
    text:            null,
    heading:		 null,
    heading-light:	 null,
    heading-dark:    null,
    link:            null,
    link-light:      null,
    link-dark:       null,
    footer:          null,
    footer-dark:     null,
);

    Description

    Default configuration schema map merged into each color registry entry.

    Type

    Map

    Map structure

    Map key NameMap key DescriptionMap key TypeMap key Value
    color

    Color slug identifier (e.g. primary, neutral-alt)

    		String— none
    text

    Contrast mode (light, dark, dark-light, light-dark, no-fallback)

    		String— none
    heading

    Global heading action (inherit, dark, light, lighten, darken, accent)

    		String— none
    heading-light

    Light-mode heading override

    		String— none
    heading-dark

    Dark-mode heading override

    		String— none
    link

    Global link ink action (inherit, dark, light, lighten, darken, highlight, highlight-alt)

    		String— none
    link-light

    Light-mode link ink override

    		String— none
    link-dark

    Dark-mode link ink override

    		String— none
    footer

    Global footer action

    		String— none
    footer-dark

    Dark-mode footer override

    		String— none

    Used by

    • [mixin] apply-colors-global
