    registry-defaults

    $registry-defaults: (
	block:   '*',          // Block wildcard [class*="wp-block-"]
	is:      'none',       // Don't require specific classes
	has:     'a, button',  // Default to requiring an embedded link or button
	exclude: '.alignfull', // Don't let full-width blocks become cards
	trigger: 'self',       // Default hover trigger to the block
	target:  'self',       // Default target class to receive animation to the block
	spacing: false,        // Add margin only to html buttons
	role:    'object'      // Default role to Object
);

    Description

    Centralized Block Registry Configuration Map.

    Maps WordPress Gutenberg blocks to physical roles, structural gates, and interaction scopes. SETUP DEFAULTS SO WE DON'T HAVE TO INCLUDE ALL FIELDS IN THE REGISTRY

    Type

    Map

    Map structure

    Map key NameMap key DescriptionMap key TypeMap key Value
    block

    Base block selector or wildcard

    		String'*'
    is

    Mandatory CSS class filters (e.g. .has-background)

    		String'none'
    has

    Required structural child gate

    		String'a, button'
    exclude

    Excluded container contexts

    		String'.alignfull'
    trigger

    Action boundary selector

    		String'self'
    target

    Kinetic animation target selector

    		String'self'
    spacing

    Structural spacing override flag

    		Booleanfalse
    role

    Role classification: card | object | object-zoom | object-grow | button

    		String'object'

    Used by

    • [mixin] apply-card-logic
    • [mixin] apply-object-logic
    • [mixin] apply-button-logic
